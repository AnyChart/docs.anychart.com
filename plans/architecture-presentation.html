04

One Dockerfile, Many Containers

One Dockerfile → builds any branch into a container Production: branch=v8 IS_STAGING=false → docs.anychart.com :8080 Staging: branch=develop IS_STAGING=true → docs.anychart.stg :8081 DVF Preview: branch=DVF-5001 IS_STAGING=true → localhost :8082 Same code. Same Dockerfile. Different env vars → different behavior.

Multi-stage build: Node.js builds the site → nginx serves static files. Final image is ~60MB with no runtime dependencies.

06

Cross-Repo Automation

Developer pushes DVF-5000 to AnyChart/AnyChart │ ▼ GitHub Actions triggers automatically │ ├── CDN build published at cdn.anychart.com/releases/DVF-5000/ │ └── Matching branch created in docs.anychart.com │ ▼ Docs writers edit the DVF-5000 docs branch │ ▼ Merge to develop → staging rebuilds

No manual branch creation. No manual CDN coordination. Push code → docs branch appears automatically.
