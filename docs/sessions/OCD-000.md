## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Docusaurus 3.x over VitePress/Starlight | Native versioning, largest ecosystem, active maintenance |
| `markdown.preprocessor` over remark plugins | Custom `{...}` directives parsed as JSX by MDX before remark runs |
| `markdown.format: 'detect'` | .md files use CommonMark, avoids HTML attribute conversion issues |
| `routeBasePath: '/'` | Docs-only mode at root level |
| Original URLs via `slug:` frontmatter | SEO preservation of existing backlinks and Google index |
| `trailingSlash: false` | Prevents duplicate canonical URLs |
| GitHub OAuth App (not GitHub App) | Simpler for community edits, public repo fork-based PRs |
| Single server process (Express) | Serves both static build and API — one process, clean internal separation |
| `@easyops-cn/docusaurus-search-local` | Free, no external service, works well for ~421 pages on VPS |

## Issues & Blockers

| Issue | Resolution |
|-------|-----------|
| `routeBasePath: '/'` + versioning has known bugs | Documented for future versioning work |
| `{...}` directives parsed as JSX | Solved with preprocessor running before MDX parser |
| Source has `##NoSpace` headings | Migration script adds space after `#` marks |
| Same-name docs (e.g. `quick-start/quick-start.md`) | Handled as category index pages with adjusted sibling links |
| Special chars in slugs (`%`, `+`) | URL-encoded: `%25`, `%2B` |
| Sample text unreadable (white on white) | `prepare-samples.mjs` injects visible base styles |
