### Variant Pages Pattern (~80 files)

These are intentionally brief — e.g. `vertical/area-chart.md` says "see [Area Chart] for settings, here's how to make it vertical" + quick start + sample. This is the correct pattern for variant pages. No action needed.

### Category Landing Pages

12 categories have NO overview page. 39 of 41 use `generated-index` (auto-generated link list) instead of pointing to a real doc. The 28 existing `overview.md` files are regular docs, not the category landing page.

**Fix approach:** Switch `_category_.json` to `type: doc` where overview.md exists, create overview pages where missing.
